Replace rules & IP toggles

Sample text for the replace rules and the "Always scramble IPv4/IPv6" toggles. Replacements only appear after you create the rules listed below on the Occulto options page. Emails and IP addresses are detected by the default config, so they are blurred (or scrambled) as usual.

IPv4 addresses

Internal host 192.168.10.42 answers on port 443; the backup gateway is 10.0.0.7.

Non-ASCII names (add a detection pattern such as Zoë Müller|Иван Петров|山田太郎, set Scramble mode: every letter should change)

Contacts: Zoë Müller, Иван Петров and 山田太郎 joined the call.

IPv6 addresses

Documentation range host 2001:db8::ff00:42:8329 and link-local router fe80::1.

Rules to create on the Occulto options page (Replace rules table):
  1. Acme → Contoso, Whole word on, Case sensitive off. Expect "Acme Corp" to become "Contoso Corp" and "Acmeware" to stay unchanged.
  2. Société Générale → Example Bank. Expect the accented name to be replaced in full.
  3. Regex on: (\w+)@acme\.com → $1@example.com. Expect the email address to stay hidden (blurred or scrambled) rather than being rewritten: censor wins over replace when they overlap. The word "Acme" inside the email is also hidden, not replaced.

IP toggles: with the mode set to Blur, turn on "Always scramble IPv4" and "Always scramble IPv6". The four addresses above should then appear scrambled instead of blurred.
